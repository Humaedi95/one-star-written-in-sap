A houseplant's one-star review of its human owner, written as a single line
under 280 characters. The program writes the review to `/output/entry.txt`.

## Run

```sh
node main.ts
```

Entry (173 characters):

> One star. He waters me like a guilty apology, shoves me into a sunless
> corner for the aesthetic, then tells guests I'm 'low-maintenance' while I
> photosynthesize in the dark.
